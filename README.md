# The 10x Recruiter

Hi, I'm Jan. I spent 4 years as an independent researcher on applied AI — building an army of agents to scale productivity — most recently doing DX/DevRel at [Parallel](https://x.com/p0) (search infrastructure for AI agents). Now I'm founding engineer at [Hyre](https://hyre.io), where my mission is to give rise to the **10x recruiter**: every conversation captured, every follow-up handled, every ATS field written back by agents. Recruitment runs on conversations — email, LinkedIn, phone, meetings — and we're building the AI layer that turns all of it into structured action.

I work on and with MCP, OpenAPI, OAuth, Cloudflare, and many gen-ai API products. I love good standards. Learn more via my [top posts on X](https://x.com/search?q=from:janwilmake%20min_faves:20&src=typed_query&f=top). Check out https://lists.forgithub.com/janwilmake for lists I keep track of.
